## Editing that wins
**Core Pattern: Evidence-First Editing. If a tool or document is mentioned, it must be on screen within 500ms.**

* **The Diagram Backbone:** Use a single, complex diagram as the visual base, animating only the nodes being discussed (ByteByteGo S4tLX3kq4Ik 3.74x, Yj9qOWnipTQ 2.18x).
* **Physical Evidence:** Holding a physical object (Remote dX_fna-Bx4E 5.0x, Paper Form VRnKIWK4tmo 18.03x) grounds the narrative in reality.
* **Split-Screen UI:** Keep the narrator in a bottom PiP/Split-screen while the top half shows real-time UI navigation (VarunMayya dmSAVk8vwTw 8.44x, biAwtOHBve8 4.05x).
* **Yellow Highlight Proof:** Use yellow highlights on key words/buttons to guide the eye (VarunMayya biAwtOHBve8 4.05x, SarkariDNA QNd3SjbXb9o 8.2x, VRnKIWK4tmo 18.03x).

## Sound
* **Voice:** High-energy, fast-paced delivery (IshanSharma7390 EQBLRjWmNBk 36.0x).
* **Music:** Upbeat, tech-focused beds (aevytv LoJnv_8Q-ec 2.8x). **Exception:** Technical/utility explainers succeed with **zero music** to emphasize authority (ByteByteGo S4tLX3kq4Ik 3.74x, SarkariDNA VRnKIWK4tmo 18.03x).
* **SFX:** Use "whooshes" for transitions and "clicks/pops" for UI interactions (VarunMayya biAwtOHBve8 4.05x, TechWiser dX_fna-Bx4E 5.0x).

## Pacing numbers
* **Visual Change Rate:** Aim for 1.5s–3.0s per shot (IshanSharma7390 EQBLRjWmNBk 36.0x at 1.5s). 
* **Spoken Density:** Target 2.5–3.5 words per second (IshanSharma7390 EQBLRjWmNBk 36.0x at 2.8). Flops occur when density drops below 1.0 wps (zackdfilms GycFYrtbVqw 0.14x).
* **Captions:** 3–6 words per chunk, centered. Use yellow highlights for key nouns (TheAIUniversity jLRIxgyr2hs 22.99x).

## What flops
1. **The "Ad-Vibe" Bait:** Transitioning from a personal hook into a sponsored tutorial kills retention (dhruvrathee fHU4neQCpkc 0.18x, aevytv XSXv0JLHp7Y 0.24x).
2. **Visceral/Gross Content:** Triggers safety filters (zackdfilms EHhqfU1kXxQ 0.13x).
3. **Tutorial Drag:** Spending >30s on a technical "how-to" without escalating stakes (VarunMayya OlFMwxTI3bk 0.18x).
4. **Missing Captions:** High-quality visuals fail without text anchors (zackdfilms EHhqfU1kXxQ 0.14x).

## Never
* Glows/neon, particle bursts, crossfades, bouncy easing, text in corners, HUD counters, stat slides, slide/deck layouts, stock-template looks, idle breathing loops, dead time >1s, anything appearing before it is spoken, invented facts, mock UI where a real screenshot exists.

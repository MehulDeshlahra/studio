# Studio channels (one engine, one folder per channel)
From MASTER-PLAN.md (16 Nov): 2-3+ Instagram pages, each posting daily quality reels, fully automatic on the
Oracle server, ₹0. One generic engine; each channel = `channels/<id>/channel.json` + its own `bible.md`
(look, cast, tone, rules) + its own `lessons.md` and `results.md`. Shared lessons stay in `knowledge/lessons.md`.

## Characters: a cast per channel, never one mascot for everything
- tech: no fixed mascot. Each topic's object is the hero (chip, battery, SIM, router, UPI server). Same 3D look
  (glossy Pixar-style, navy studio, yellow accent), so the page still looks like one brand. Objects can come back
  when a topic links (Battery returns in "fast charging").
- raaz: one recurring narrator-detective (face kept the same through a fixed description) + case-specific cast.
- katha: the story's own figures, drawn with respect, one fixed painterly style.
- The brand is carried by: colours, title style, voice, sound logo, caption style, hook pattern, not by one character.
